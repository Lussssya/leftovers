# Project preferences

Write beginner-friendly C# throughout this project. Use clear names, explicit
types, short methods, and ordinary if/else statements. Avoid code comments,
decorative Inspector headers, expression-bodied methods, nested ternaries,
LINQ, and unnecessary abstractions. Keep existing Unity field names and .meta
files when simplifying code so Inspector values and references survive.

Preserve teammate work and the user's tuned settings. Make small changes in the
existing folder structure. After each major change, explain what changed and
how to test it in Unity. Do not change packages, input systems, or render
pipelines unless the task requires it.
